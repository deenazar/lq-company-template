# Code Review

## Check
- Works per the acceptance criteria
- Follows the folder-structure skill
- Follows the design-system skill
- No console errors
- No secrets in code
- Input validation
- TypeScript has no `any`
- Tests cover the logic
- Mobile 360px width works

## Report
Group findings as **High / Medium / Low**.
